# SWIM PACE

水泳部の練習メニュー「50m × 14（4H1E3H1E2H1E1H1E）」用の目標タイム管理アプリ。

## 機能

- 選手の追加・編集・削除、名前や選択リストでの絞り込み
- 種目、ベストタイム、長水路／短水路、1HのAを登録
- A＝理想、B＝A＋1秒、C＝A＋2秒
- 2H・3H・4Hは1Hからそれぞれ＋1秒・＋2秒・＋3秒
- 全12個の目標タイムを自動計算
- データを含む共有リンクの作成
- スマートフォンのホーム画面追加用マニフェスト・アイコン

## 起動

依存パッケージやビルドは不要です。リポジトリのルートで以下を実行し、表示されたローカルURLを開きます。

```sh
python -m http.server 8000
```

Node.jsがある場合は `node --test tests/app.test.cjs` でテストできます。

静的ホスティングでは、このフォルダの内容をそのまま配信できます。ホーム画面への追加にはHTTPSの利用を推奨します。iPhoneはSafariの共有メニュー、AndroidはChromeのメニューから追加します。端末により表示は異なります。オフライン対応は含みません。

## 個人情報の扱い

このGitHub版は、選手名・記録・選手別目標タイムを一切含まず、空の状態で起動します。実データや既存の公開サイトへのリンク、旧サイトのGit履歴、ホスティング設定は含みません。

入力内容は利用者のブラウザのlocalStorageに保存します。サーバーへのデータ保存・端末間自動同期はありません。ベストタイムから1HのAへの換算は行わず、Aは別途入力します。

「共有リンク」には登録した全選手のデータがURLフラグメントとして入ります。暗号化やアクセス制限はなく、リンクを知っている人は閲覧できます。共有後の変更は自動反映されません。実データを入れたリンク・画面画像・エクスポートをGitHubのIssue、README、コードに貼らないでください。

`.gitignore`は補助です。個人情報をソースに直接書き込んだ場合は防げないため、コミット前に差分を確認してください。
